# EngFore Vision

Version: 1.0 (MVP)

---

# Product Name

**EngFore**

---

# Tagline

> Stop Guessing. Start Typing.

---

# Vision

EngFore is a minimalist English practice platform built around one principle:

> People remember what they actively recall, not what they recognize.

Instead of using multiple-choice quizzes, users must type every answer correctly.

EngFore does not teach English.

It helps users remember the English they have already learned.

---

# Mission

Build the fastest and cleanest environment for practicing English vocabulary through active recall and text-entry testing.

Every feature must improve learning efficiency.

Every unnecessary feature must be removed.

---

# Problem

Most English learning applications rely heavily on recognition.

Examples:

- Multiple choice
- Matching
- Fill in the blank
- Flashcards with visible answers

These methods often create the illusion of learning.

Learners recognize the correct answer but fail to produce it in real situations.

---

# Solution

EngFore replaces recognition with recall.

Workflow:

Meaning

↓

Think

↓

Type

↓

Validate

↓

Repeat

Users cannot continue until they type the correct answer.

---

# Core Philosophy

## Active Recall

Users must retrieve knowledge from memory.

---

## Text-entry Testing

Every answer is typed.

Never guessed.

---

## Minimalism

Remove everything that does not improve learning.

---

## Keyboard First

The keyboard is the primary interaction method.

---

## Private by Default

All vocabulary belongs only to its owner.

No community.

No public sharing.

---

# Design Principles

Fast.

Quiet.

Minimal.

Professional.

Developer-oriented.

---

# What EngFore is NOT

EngFore is NOT:

- Duolingo
- An online course
- A social network
- A vocabulary marketplace
- A gamified learning app

---

# Target Users

Primary:

- University students
- Developers
- Self-learners

Secondary:

- IELTS learners
- TOEIC learners
- English learners who already have learning materials
