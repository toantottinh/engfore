# Landing Page Specification

Version: 1.0 (MVP)

---

# Goal

The landing page introduces EngFore in less than 15 seconds.

Visitors should immediately understand:

- What EngFore is
- Why it is different
- How it works
- Try the demo
- Create an account

The page must feel like a modern developer tool rather than an online English course.

---

# Design Principles

- Dark Mode Only
- High Contrast
- Minimal
- Keyboard-first
- No unnecessary animation
- Large spacing
- Fast loading
- Typography-focused

Inspired by:

- Vercel
- Linear
- Raycast
- GitHub

# Anti-patterns

Do NOT use:

- Mascots
- Confetti
- Sound effects
- Large illustrations
- Heavy gradients
- Busy layout
- Gamification

The user should feel like using a professional productivity tool.
